Solution at θ = 60°

  1. Coordinates (from the figure): O(0, 0, 0), A(0, 12cos60°, 12sin60°) = (0, 6, 10.392), B (−2.6, −3, 0), C (6, −3, 0), W acts at the midpoint G (0, 3, 5.196).
  2. Unit vectors. AB = (−2.6, −9, −10.392), |AB| = 13.99 m → uAB = (−0.1858, −0.6433, −0.7428).
    AC = (6, −9, −10.392), |AC| = 15.00 m → uAC = (0.4000, −0.6000, −0.6928).
  3. ΣMO = 0: rOA × (TABuAB + TACuAC) + rOG × W = 0.
    y-moment: −1.9310 TAB + 4.1569 TAC = 0 → TAC = 0.4645 TAB
    x-moment: 6(−0.7428)TAB − 10.392(−0.6433)TAB + [6(−0.6928) − 10.392(−0.6)]TAC = 105 → 2.2283 TAB + 2.0785 TAC = 105
  4. Solve: TAB = 32.88 kN, TAC = 15.27 kN.
  5. ΣF = 0 at O: Ox = 0, Oy = 30.31 kN, Oz = 70.00 kN → RO = √(30.31² + 70²) = 76.28 kN.

Assumes B = (−2.6, −3, 0) and C = (6, −3, 0) as read from the dimension lines (6 m and 3 m locate C; 2.6 m locates B on the same −3 m line). If your answer key uses different coordinates, change B and C at the top of the script.
